# Instruções para trabalhar neste repositório

- Desenvolva a partir deste repositório; não importe código do projeto antigo automaticamente.
- Preserve alterações existentes e trabalhe com orçamento de R$ 0. Não contrate serviços.
- Não faça commits ou push sem autorização explícita. A branch principal é `main`.
- Antes de entregar alterações, rode `npm run check` e `npm run build`; informe qualquer verificação bloqueada.
- Não avance para cadastro, planos ou cobrança sem aprovação da próxima etapa.
- Mantenha segredos fora do Git, do navegador e dos logs. Não colete dados de cartão nem CVV.
- Mercado Pago somente em testes. O redirecionamento do checkout e a autorização da assinatura, por si sós, nunca concedem Premium.
- Atualize os documentos em `docs/` quando uma decisão mudar.
